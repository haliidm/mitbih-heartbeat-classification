# V5 心搏后处理规则

实现：`mitbih_aami/beat_postprocess.py`、`label_cleanup.py`。App与当前评估入口共享规则；在完整记录上处理后才截取显示窗口。

1. **区域与100ms过滤**：连续非0标签作为同一区域，N→S→V但中间没有0仍是一个区域。V5不填补背景缝隙。全部不足100ms的区域删除，包括内部与边界区域。
2. **上下文短区域过滤**：180—500ms（含端点）视为正常宽度。用这些区域中心间的300—2000ms间距估计典型RR（中位数），至少需要3个有效间距。对不足180ms的内部区域，只有当左右紧邻区域均为正常宽度、两侧中心距离在300—2000ms且落在典型RR的±25%内，并且至少一侧背景间隔小于180ms时，才删除它。判定使用本步骤删除前的同一份区域列表。
3. **定位与长区域拆分**：不超过500ms按区域中点定位。超过500ms，在预处理ECG绝对幅值上找峰；峰间至少200ms，峰高至少为区域绝对幅值95分位数的45%，突出度至少为该尺度35%且不低于0.3标准化幅值。至少2个候选峰才按相邻峰中点拆分，并以候选峰定位；否则保留一个区域、按中点定位。拆分后的子区域不再次应用前面的短区域过滤。
4. **类别判定与绘图**：最终区域中N类点占比严格大于10%则判N，否则取最多的非0类别；并列时取编号较小的类别。App将整个最终区域涂为最终类别。
5. **与测评区分**：V5预测后处理不使用ATR决定拆分或类别。参考峰校正与位置容差匹配属于独立流程；±150ms容差不改变预测区域。

毫秒阈值按采样率换算并取整；区域采用左闭右开边界，中点为(start+end-1)//2。

发布预处理为0.67—40Hz带通与整记录z-score，必要时重采样。未验证的Icentia异常区段排除、缺失插值不包含在本次发布中。
