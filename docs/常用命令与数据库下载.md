# ECG 常用命令、评估表格和数据库下载

所有命令在 PowerShell 中运行。仅复制需要执行的代码块；评估和训练会占用本机计算资源。

## 1. 进入项目

在克隆仓库的父目录打开终端：

```powershell
cd mitbih-heartbeat-classification
```

如使用 Conda，可创建通用环境（仅首次需要）：

```powershell
conda create -n ecg python=3.12 -y
conda activate ecg
```

之后按 README 安装依赖，统一使用 `python` 运行命令，无需写个人电脑的解释器绝对路径。

## 2. 发布的评估结果

### MIT-BIH 和 ST-T

[实验结果汇总](../reports/发布结果汇总.md)

| 模型 | MIT-BIH 目录 | ST-T 目录 |
|---|---|---|
| 16 秒 | `runs/mitbih_16s_eval_v5_matrix` | `runs/stt_16s_eval_v5_matrix` |
| 32 秒 | `runs/mitbih_32s_eval_v5_matrix` | `runs/stt_32s_eval_v5_matrix` |
| 64 秒 | `runs/mitbih_64s_eval_v5_matrix` | `runs/stt_64s_eval_v5_matrix` |

以各报告标注的容差为准。下面新命令统一采用 ±150 ms。MIT-BIH 全库包含训练数据；ST-T 是外部数据库评估。分类混淆矩阵仅统计位置匹配的心搏，应同时查看 R 峰漏检和多检。

## 3. 打开 App

32 秒模型：

```powershell
python -m mitbih_aami.desktop_app --checkpoint .\checkpoints\ecg_cnn_transformer_32s.pt --postprocess v5
```

16 秒模型：

```powershell
python -m mitbih_aami.desktop_app --checkpoint .\checkpoints\ecg_cnn_transformer_16s.pt --postprocess v5
```

64 秒模型：

```powershell
python -m mitbih_aami.desktop_app --checkpoint .\checkpoints\ecg_cnn_transformer_64s.pt --postprocess v5
```

在 App 内选择记录的 `.hea` 文件；同名 `.dat` 和 `.atr` 放在同一目录。Icentia 示例：

```text
./icentia11k-continuous-ecg-1.0\p00\p00000\p00000_s00.hea
```

App 对完整记录推理，显示参考标签、原始预测标签及 V5 修正标签与信号。显示窗口为 16 秒，与模型输入长度是两个概念；前后按钮移动 10 秒。250 Hz 数据会按现有流程重采样到模型的 360 Hz。长记录需要等待推理完成。

## 4. Icentia：评估患者 00000—00049，三个模型

```powershell
python -B -u -m mitbih_aami.evaluate_icentia `
  --database-dir .\icentia11k-continuous-ecg-1.0 `
  --patient-start 0 --patient-end 49 `
  --tolerance-ms 150 `
  --output-dir .\runs\icentia_p00000_p00049_v5_150ms_Qposition
```

首尾编号均包含，共 50 名患者。自动使用 16/32/64 秒模型，各自保存报告，根目录生成 `三个模型对比.md`。缺失 ATR 的片段会记录并排除。


## 5. MIT-BIH、ST-T：三个模型全库评估

下面循环依次执行六次评估，结果写入新的 `*_150ms_manual` 目录。

```powershell
$models = @{
  '16s' = 'ecg_cnn_transformer_16s.pt'
  '32s' = 'ecg_cnn_transformer_32s.pt'
  '64s' = 'ecg_cnn_transformer_64s.pt'
}
foreach ($window in @('16s', '32s', '64s')) {
  foreach ($db in @('mitbih', 'stt')) {
    $database = if ($db -eq 'mitbih') { '.\mit-bih-arrhythmia-database-1.0.0' } else { '.\european-st-t-database-1.0.0' }
    python -m mitbih_aami.evaluate_records `
      --database-dir $database `
      --checkpoint ".\checkpoints\$($models[$window])" `
      --output-dir ".\runs\${db}_${window}_eval_v5_150ms_manual" `
      --tolerance-ms 150
    if ($LASTEXITCODE -ne 0) { throw "评估失败：$db $window" }
  }
}
```

只评估个别记录，可增加 `--records 202 209`，并给出独立输出目录，避免覆盖全库报告。Icentia 的嵌套目录请使用第 4 节专用入口。

## 6. 数据库链接及下载

| 数据库 | 官方页面 | 本地目录 |
|---|---|---|
| MIT-BIH | https://physionet.org/content/mitdb/1.0.0/ | `mit-bih-arrhythmia-database-1.0.0` |
| European ST-T | https://physionet.org/content/edb/1.0.0/ | `european-st-t-database-1.0.0` |
| Icentia11k | https://physionet.org/content/icentia11k-continuous-ecg/1.0/ | `icentia11k-continuous-ecg-1.0` |
| BCG J 峰项目数据 | https://doi.org/10.6084/m9.figshare.28416896 | 另见 BCG_JPeaks 项目说明 |

MIT-BIH 和 ST-T 可在官方页面 Files 区下载 ZIP，解压到上述目录。也可通过官方公开 S3 下载，无需 AWS 账号。

安装下载工具（仅需一次）：

```powershell
python -m pip install awscli
```

MIT-BIH：

```powershell
python -m awscli s3 sync "s3://physionet-open/mitdb/1.0.0/" ".\mit-bih-arrhythmia-database-1.0.0" --no-sign-request
```

ST-T：

```powershell
python -m awscli s3 sync "s3://physionet-open/edb/1.0.0/" ".\european-st-t-database-1.0.0" --no-sign-request
```

Icentia 仅下载 00000—00049：

```powershell
foreach ($i in 0..49) {
  $patient = "p{0:D5}" -f $i
  python -m awscli s3 sync "s3://physionet-open/icentia11k-continuous-ecg/1.0/p00/$patient/" ".\icentia11k-continuous-ecg-1.0\p00\$patient" --no-sign-request
  if ($LASTEXITCODE -ne 0) { throw "下载失败：$patient" }
}
```

如果确实需要整个 p00：

```powershell
python -m awscli s3 sync "s3://physionet-open/icentia11k-continuous-ecg/1.0/p00/" ".\icentia11k-continuous-ecg-1.0\p00" --no-sign-request
```

**整个 p00 对应 00000—00999，共 1000 名患者，不是 100 名。** 已经下载完成无需再下载。S3 下载的是可直接读取的文件，不需解压；重复 sync 会跳过满足同步条件的已有文件，但不保证未完成的单个文件按字节续传。评估期间避免修改数据库文件。

## Icentia：Q 仅参与心搏位置评分（2026-10-16 修订）

全部参考心搏（N/S/V/Q）一起进行位置一对一匹配。参考 Q 匹配成功计 RTP，漏检计 RFN；任何未匹配预测计 RFP，不因邻近 Q 而忽略。

心搏类型评分排除参考 Q：匹配到参考 Q 的预测，无论预测类别是什么，都不进入分类混淆矩阵及类别 TP/FP/FN/TN。参考 N/S/V 被预测为 Q 仍属于错分，因此矩阵保留“预测 Q”列。分类指标只报告 N/S/V。

`分类混淆矩阵.csv` 的参考行为 N/S/V，预测列为 N/S/V/F/Q。R 峰指标的匹配心搏数可以大于分类矩阵总数，差值为匹配到参考 Q 的心搏数。

使用全新输出目录避免混用旧口径：

```powershell
python -B -u -m mitbih_aami.evaluate_icentia `
  --database-dir .\icentia11k-continuous-ecg-1.0 `
  --patient-start 0 --patient-end 49 `
  --tolerance-ms 150 `
  --output-dir .\runs\icentia_p00000_p00049_v5_150ms_Qposition
```
