# 模型与实验设计

## 网络

```text
输入 B×1×L（L=5760 / 11520 / 23040）
  ↓ 三路并行：卷积核分别为 3、5、7
每路 5 层 Conv1d，步长2，通道 8→16→32→64→128
每层 GroupNorm(8组) + GELU
  ↓ 拼接
B×384×(L/32)
  ↓ 1×1卷积 + GroupNorm + GELU
B×192×(L/32)
  ↓ 可学习位置编码
TransformerEncoder ×3：192维、6头、前馈384维、dropout=0.1
无因果掩码，允许利用窗口内前后上下文
  ↓ 5级线性上采样，每级×2 + 卷积核3
通道 128→96→64→32→32
  ↓ 1×1卷积
输出 logits B×6×L（背景、N、S、V、F、Q）
```

输出为 logits；逐点 argmax 得到类别区域，之后通过 V5 规则生成心搏位置与类别。三个模型的可学习位置编码长度不同，权重需与输入窗口长度匹配。

## 标签

按当前 label_config.py 实现的 AAMI 类别映射：

| 类别 | WFDB 心搏符号 |
|---|---|
| N | N、L、R、e、j |
| S | A、a、J、S |
| V | V、E |
| F | F |
| Q | /、f、Q |

0为背景，1—5为 N/S/V/F/Q。在完整记录上，将参考位置在±50ms范围内对齐附近正向或负向峰，再生成以其为中心、半宽180ms的逐点标签。邻近心搏过密时收窄标签，避免重叠。标签表示训练目标区域，不是人工标注的真实 PQRST 起止界限。

训练采样保留 S/V/F/Q 中心窗口及全部窗内标签，额外加入少量 AFIB/AFL 背景的 N 类窗口。当前按窗口7:1:2拆分，存在同患者与重叠窗口跨集合的可能。不能宣称患者间测试结果。

## 预处理

使用0.67—40Hz带通与整记录z-score。推理支持重采样至360Hz。详见[V5后处理规则](V5后处理规则.md)。

## 评价

位置按容差进行一对一匹配。R峰报告TP、FP、FN及精确率、召回率、F1，不定义TN或特异性。分类指标基于位置匹配后的混淆矩阵；另提供包含位置漏检/多检的类别事件计数，两者口径不同。

Icentia：Q的参考位置可参与检测评分，但参考Q的匹配对不参与任何类别指标。N/S/V被预测成Q仍是错分，保留预测Q列。无F参考类别，不输出F分类指标。本仓库仅提供Icentia外部泛化评估代码，不发布其结果。
