# ECG 项目入口

## 当前模型与报告

| 输入 | 训练输出 | 最新全库评估目录 |
|---|---|---|
| 16秒，补充AFIB/AFL背景N窗口 | runs/mitbih_rhythm_n | runs/mitbih_16s_eval_v5_matrix |
| 32秒 | runs/mitbih_32s | runs/mitbih_32s_eval_v5_matrix |
| 64秒 | runs/mitbih_64s | runs/mitbih_64s_eval_v5_matrix |

模型文件为各训练目录的 best_model.pt。训练配置、划分和历史分别保存在 training_config.json、split_manifest.json、training_history.json。

## 查看模型推理

在 项目根目录 下运行：

```powershell
python -m mitbih_aami.desktop_app --checkpoint .\checkpoints\ecg_cnn_transformer_64s.pt --postprocess v5
```

换成 mitbih_32s 或 mitbih_rhythm_n 的检查点即可切换模型。模型输入长度由检查点读取；App 的显示窗口独立于模型输入长度。显式指定 v5 可使图中后处理与 V5 报告对应。

## 完整 MIT-BIH 库评估

```powershell
python -m mitbih_aami.evaluate_records --database-dir .\mit-bih-arrhythmia-database-1.0.0 --checkpoint .\checkpoints\ecg_cnn_transformer_32s.pt --output-dir .\runs\mitbih_32s_eval_v5_matrix
python -m mitbih_aami.evaluate_records --database-dir .\mit-bih-arrhythmia-database-1.0.0 --checkpoint .\checkpoints\ecg_cnn_transformer_64s.pt --output-dir .\runs\mitbih_64s_eval_v5_matrix
```

以上两个目录已有报告，再运行会更新其中的输出。16秒新版报告也已生成，对应命令：

```powershell
python -m mitbih_aami.evaluate_records --database-dir .\mit-bih-arrhythmia-database-1.0.0 --checkpoint .\checkpoints\ecg_cnn_transformer_16s.pt --output-dir .\runs\mitbih_16s_eval_v5_matrix
```

六份当前报告均已生成，整理读取已有结果。ST-T 外部评估使用同一入口，将 database-dir 改成 .\european-st-t-database-1.0.0，并使用独立输出目录。旧ST-T微调实验已归档，其模型曾用ST-T训练，应与当前仅MIT-BIH训练的模型区分。

## 代码分工

| 文件 | 用途 |
|---|---|
| mitbih_aami/train_16s.py | 16秒，S窗口加权及节律N补样训练 |
| mitbih_aami/train_long_context.py | 32/64秒训练，默认batch size 8 |
| mitbih_aami/legacy_train_s_weighted.py | 较早的S加权重训入口 |
| mitbih_aami/legacy_train_baseline.py | 基础训练入口 |
| mitbih_aami/legacy_finetune_stt.py | ST-T微调入口 |
| mitbih_aami/ecg_data.py | 数据读取、采样率适配、预处理、峰位校正和标签 |
| mitbih_aami/cnn_transformer.py | 多尺度卷积分支、Transformer、逐点解码 |
| mitbih_aami/record_inference_metrics.py | 整条记录滑窗推理与拼接 |
| mitbih_aami/beat_postprocess.py | V5区域后处理 |
| mitbih_aami/evaluate_records.py | 当前完整记录评估入口 |
| legacy_evaluate_records_v4.py、legacy_beat_postprocess_v4.py、label_cleanup.py | 仍被微调入口或App/V5调用的依赖；保留 |
| mitbih_aami/desktop_app.py | 桌面查看工具 |
| 1.py | 打印Python解释器路径的小诊断脚本 |
| tools/summarize_results.py | 读取已有结果、更新汇总，不加载模型 |
