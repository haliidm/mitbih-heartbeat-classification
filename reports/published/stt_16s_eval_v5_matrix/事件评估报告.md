# 完整记录心搏评估报告（规则五）



位置匹配阈值：±150 ms

V5不填补背景缝隙；保留小于100毫秒过滤及V4上下文短段过滤。不超过500毫秒的区域按中点定位；更长区域在预处理ECG绝对幅值上寻找候选峰，峰间至少200毫秒，高度至少为区域绝对幅值95分位数的45%，突出度至少为该尺度的35%且不低于0.3标准化幅值。至少两个候选峰才按相邻峰中点分割，拆分区域用候选峰定位；候选峰不足两个时保留一个区域并按区域中点定位，不强行等分。每个区域N占比大于10%判N，否则按主类别；不使用ATR确定拆分点。

R 峰检测只统计 TP、FP、FN，并计算阳性预测值、敏感度和 F1；没有定义真实阴性候选，因此不计算特异性。

五分类混淆矩阵仅包含位置匹配的心搏；矩阵行为参考类别，列为预测类别。分类指标按该矩阵计算。位置未匹配的漏检/多检在 R 峰检测及事件计数中单独体现。

混合区域判类：区域内 N 类点占比大于 10% 时，该区域按 N 类计。

长区域按ECG候选峰拆分，候选峰不足两个不强行拆分；详见各记录long_regions.json。
